
# IELTS Writing Band 9 Training App — Final PRD

## 1. Product Overview

### 1.1 Purpose
A web-based training tool that helps users achieve IELTS Writing Band 9 through:
- Personal template memorization
- Rapid point generation using mnemonics + topic banks
- Component-level drilling (Opening, Body, Counter-Argument)
- Logic flow mastery
- Comparison-based feedback (not scoring)

### 1.2 Core Promise
We provide:
- Structured practice modes for Task 1 (33%) and Task 2 (67%)
- Template building and memorization support
- Component drills for when template can't be used directly
- Comparison against Band 9 models
- Categorized error detection

We do NOT provide:
- Band score predictions
- Holistic judgments

### 1.3 Core Training Philosophy

**The Template Strategy:**
1. **Craft** a personal Band 9 template with sophisticated language
2. **Memorize** the template word-for-word
3. **See prompt** → generate points using mnemonics (P$ICC, HESHEIT, GETQC, CFFSUP)
4. **Develop points** using topic-specific idea banks
5. **Fill in** the blanks
6. **Write 500+ words** consistently

**The Backup Strategy (Component Drills):**
When template can't be used directly (unusual question format, forgot sections):
- Opening Drill → master Hook → Transition → Stance
- Body Drill → master High → Mid → Detail logic flow
- Counter-Argument Drill → master Concession → Rebuttal

## 3. Task 2 — Structure and Formulas

### 3.1 Question Types

| Type | Frequency | Approach |
|------|-----------|----------|
| A: Discuss Both Views | 19.2% | MP1 = View A, MP2 = View B, MP3 = Your stance |
| B: To What Extent | 30.8% | Standard 3-point (ACTS/SFVS) |
| C: Positive/Negative Development | 15.4% | ACTS (Effects) |
| D: Advantages Outweigh Disadvantages | 7.7% | MP1-2 = Advantages, MP3 = Acknowledge disadvantages |
| E: Problems/Causes/Solutions | 26.9% | ICSS framework |

### 3.2 Core Frameworks

**ACTS (Effects-type):**
- **A**ction → **C**ontext → **T**arget Effects → **S**cope

**SFVS (Facts-type):**
- **S**tatement → **F**acts → **V**erdict → **S**cope

**ICSS (Two-part analysis):**
- **I**ssue → **C**auses/Effects → **S**olutions → **S**cope

### 3.3 Opening Paragraph

**Goal:** Hook → Transition → Points (Stance)

**Six Approaches:**
1. Controversy (A vs B → my stance)
2. Examples
3. Examples + Question + parallel
4. Comparison and contrast
5. Definition
6. Directly addressing the audience

**Formula:**
```
It is hard to deny that [opposite detail], and such a fact leads 
impressionable people to generate the opinion that [opposite response]. 
However, such a statement suffers from both logical and factual 
fallacies, and it should be examined meticulously. As far as [point1], 
[point2], and [point3] are concerned, I strongly hold that [our response].
```

### 3.4 Body Paragraphs

**Logic Flow (Critical):**
```
High Level (Topic Sentence)
     ↓
Mid Level (Explain/Elaborate)
     ↓
Detail (Examples/Reasoning)
     ↓
Small Conclusion
```

**Requirements:** (1) Coherent, (2) Adequate, (3) Consistent

**MP1: Reasoning**
```
TS → Why (logic) → Current Problem → +ve/-ve implications → SC
```

**MP2: Exemplification**
```
TS → Importance of TS → Example → SC
```

**MP3: Counter-Argument**
```
Hook (acknowledge) → Point (state counter) → Reasoning (rebut)
```

### 3.5 Counter-Argument Formulas

**Strategy 1: Alternative Methods**
```
Opponents may counter my stance, claiming that.... Undeniably, .....; 
however, alternatives are always readily available.... Evidently, 
there is no need to....
```

**Strategy 2: Causal Breakdown**
```
A leads to B
A + C will not lead to B (REMEDY)

Formula:
Nevertheless, a voice arises that [opposite opinion]. Ironically, 
[facts against opposite detail]. Therefore, [Point 3].
```

### 3.6 Conclusion

**Five Skills:**
1. Summary (paraphrase)
2. Concession
3. Suggestion
4. Call for action
5. Quote

**Formula:**
```
In a nutshell, I maintain that [paraphrased response]. Admittedly, 
[concession]. However, [final reinforcement].
```

### 3.7 Band Progression

| Band | Characteristics |
|------|-----------------|
| 8 | Very good logic; 極低可抬杠性; plausible evidence; accurate language |
| 8.5 | Almost error-free; 6-8 min double-check buffer |
| 9 | 優化論點; format variety; 論點清晰，主題明確，不重不漏 |

- **C**ompare: Key comparisons
- **G**eneral Trend: Overall pattern
- **M**in/Max: Extremes

- Introduction: Paraphrase (1-2 sentences)

- Body 1: Main features
- Body 2: Secondary features

### 4.3 Vocabulary Reference

**Proportions:**
| Percentage | Phrase |
|------------|--------|
| 100% | all of the... |
| ~90% | nearly all / the vast majority of the... |
| ~75% | many of / the majority of the... |
| 50-75% | well over half / more than half of the... |
| 50% | half of the... |
| 40-50% | nearly/about half of the... |
| ~30% | a third of the... / only a minority |
| 25% | a quarter of the... |
| 20% | a fifth of the... |
| ~10% | only very few / only a minority |
| 0% | none of the... |

**Trends:**
| | Moderate | Dramatic | Extreme |
|---|----------|----------|---------|
| Up | rise, increase, grow, climb | jump, surge, soar | skyrocket, peak at |
| Down | dip, fall, decline, drop | slide, plunge, slump | hit bottom |

**Processes:** initially, the next step is, subsequently, simultaneously, finally

**Tone:** Surprisingly, remarkably (+ve); Lamentably, regrettably (-ve)

## 6. Question Bank

### 6.1 Task 2 Questions

#### Type A: Discuss Both Views (19.2%)

1. Some people think that environmental problems should be solved on a global scale, while others believe it is better to deal with them nationally. Discuss both sides and give your opinion.

2. All parents want the best opportunities for their children. There are some people who think that schools should teach children skills, but others think having a range of subjects is better for a children's future. Discuss both sides and give your opinion.

3. There seems to be an increasing number of serious crimes committed each year. While some think the best way is to use the death penalty as a deterrent, many people believe that other measures will be needed. Discuss both sides.

4. Completing university education is thought by some to be the best way to get a good job. On the other hand, other people think that getting experience and developing soft skills is more important. Discuss both sides and give your opinion.

5. Some people think that exercise is the key to health, while others feel that having a balanced diet is more important. Discuss both sides and give your opinion.

6. It is thought by some that it is better to live in a city, while others believe that life is better in the countryside. Discuss both sides and give your opinion.

7. Some people think that the internet has brought people closer together, while others think that people and communities are becoming more isolated. Discuss both sides and give your opinion.

#### Type B: To What Extent / Opinion (30.8%)

1. "Prevention is better than cure". Researching and treating diseases is too costly so it would be better to invest in preventative measures. To what extent do you agree?

2. With the increased global demand in oil and gas, undiscovered areas of the world should be opened up to access more resources. To what extent do you agree?

3. We live in a world of technology these days. While the internet brings with it clear advantages, the problems in terms of control and security of information outweigh the advantages. To what extent do you agree?

4. In many countries today, parents are able to choose to send their children to single-sex schools or co-educational schools. Some people think that children going to single-sex schools have disadvantages later in life. To what extent do you agree?

6. Some people think that success is the best measure for intelligence, while others think that intelligence can be measured in other ways. What is your opinion?

7. The growing number of overweight people is putting a strain on the health care system in an effort to deal with the health issues involved. Some people think that the best way to deal with this problem is to introduce more physical education lessons in the school curriculum. To what extent do you agree or disagree?

8. Some people believe that men and women are equal and so women should be able to do any job they want. Others feel that men and women are not equal and therefore there are certain jobs which are not suitable for women. What is your opinion?

9. Some people think that more money should be spent on protecting endangered species while others think it is a waste of valuable money. What is your opinion?

---

#### Type D: Advantages/Disadvantages (7.7%)

1. It is becoming increasingly popular to have a year off between finishing school and going to university. What are the advantages and disadvantages of this?

2. Some people think that it would be better for large companies and industry to move to regional areas outside large urban centers. Do you think the advantages outweigh the disadvantages?

3. With the rise of e-books comes the decline in paper books. Some people see this as a good step forward while others do not. What are the advantages and disadvantages of this trend?

4. The rise of convenience foods has helped people keep up with the speed of modern life. What are the advantages of this trend? Do the advantages outweigh the disadvantages?

5. There seems to be an increasing trend towards assessing students through exams rather than continual assessment. What are the advantages and disadvantages of exams as a form of assessment?

6. Space exploration costs taxpayers an exorbitant amount of money each year. What are the advantages and disadvantages of spending money on space exploration?

7. Many elderly people are no longer looked after by their families but are put in care homes or nursing homes. What are the advantages and disadvantages of this trend?

---

#### Type E: Problems/Causes/Solutions (26.9%)

1. In many developing countries, there is a problem with declining quality of air and water from both industry and construction. What measures could be taken to prevent this?

2. Many offenders commit more crimes after serving their first punishment. Why is this happening, and what measures can be taken to tackle this problem?

3. With the development of social media, more and more youngsters are being allowed unsupervised access to the internet in order to meet and chat with friends which can lead to potentially dangerous situations. What solutions can you suggest to deal with this problem?

4. Overpopulation in many major urban centers around the world is a major problem. What are the causes of this? How can this problem be solved?

5. More and more wild animals are on the verge of extinction and others are on the endangered list. What are the reasons for this? What can be done to solve this problem?

6. Many small, local shops are closing as they are unable to compete with large supermarkets in the area. How does this affect local communities? How could this situation be improved?

7. An increasing number of professionals, such as doctors and teachers, are leaving their own poorer countries to work in developed countries. What problems does this cause? What solutions can you suggest to deal with this situation?

## 7. Vocabulary Reference System

### 7.1 Structure Phrases

**Introduction:**
```
- "It is clearly seen from the above that..."
- "After detailed consideration, I believe that..."
- "I am strongly committed to the idea that..."
- "All in all, I am of the opinion that..."
```

**First Argument:**
```
- "There are a number of reasons why [SVO], the first being that..."
- "The arguments for my stance are numerous, with [noun phrase] being the most significant one."
- "First and foremost, it is evident/apparent/clear that..."
- "To start with, we must bear in mind that..."
- "The first point to be noted is that..."
```

**Second Argument:**
```
- "Closely connected with the above point is that..."
- "What must also be taken into consideration is that..."
- "Another factor often overlooked is that..."
- "Equally important is the argument that..."
- "In addition to [Point A], [Point B]..."
```

**Final Argument:**
```
- "Last but not least..."
- "Above all..."
- "Perhaps the most essential factor is that..."
- "My final point has to do with the fact that..."
```

**Counter-Arguments:**
```
Reporting: argue, assert, claim, contend, insist, maintain
Critique: counter, attack, criticize, question, be skeptical of
Weak: invalid, untenable, unjustifiable, ill-founded, groundless, implausible, flawed, specious
Strong: valid, tenable, justifiable, well-founded, reasonable, convincing, compelling
```

**Conclusions:**
```
- "Taking all aspects into consideration, we can clearly see that..."
- "All in all / On the whole / By and large / To sum up..."
- "From what has been examined above, the claim that [SVO] is unsubstantiated."
```

**Small Conclusions:**
```
- "With this in mind, it is clear that..."
- "It is therefore unwise for [Subject] to [Verb]..."
- "This, undoubtedly, explains why..."
```

### 7.2 High-Level Connectors

